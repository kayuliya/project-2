# Примитивная база данных

Простая консольная база данных на Python. Таблицы и записи хранятся в JSON-файлах,
поддерживаются операции создания и удаления таблиц, а также CRUD-операции над данными
(insert / select / update / delete). Ошибки обрабатываются декораторами, опасные
операции требуют подтверждения, а повторные `select` кэшируются.

## Установка и запуск

    uv sync
    uv run database

## Управление таблицами

Команды:
- `create_table <имя> <столбец:тип> ...` — создать таблицу (типы: int, str, bool; столбец ID:int добавляется автоматически)
- `list_tables` — список таблиц
- `drop_table <имя>` — удалить таблицу
- `help`, `exit`

## CRUD-операции

- `insert into <таблица> values (<значение1>, <значение2>, ...)` — создать запись (ID задается автоматически, строки в кавычках)
- `select from <таблица>` — вывести все записи
- `select from <таблица> where <столбец> = <значение>` — вывести записи по условию
- `update <таблица> set <столбец> = <значение> where <столбец> = <значение>` — обновить записи
- `delete from <таблица> where <столбец> = <значение>` — удалить записи
- `info <таблица>` — информация о таблице

## Обработка ошибок и подтверждение действий

- Ошибки (несуществующая таблица или столбец, неверный тип значения) обрабатываются декоратором и не прерывают работу программы.
- Опасные операции (`drop_table`, `delete`) запрашивают подтверждение `[y/n]`.
- Время выполнения `select` и `insert` выводится в консоль; повторные одинаковые `select` берутся из кэша.
